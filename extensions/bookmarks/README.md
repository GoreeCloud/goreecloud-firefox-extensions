# GoreeCloud Bookmarks Firefox Extension

Canonical Firefox-extension directory for the GoreeCloud Bookmarks browser integration.

Current migration source: `GoreeCloud/goreecloud-bookmark-browser-extension`.

The legacy repository contains cross-browser material in addition to Firefox support. During migration, Firefox-maintained source and genuinely shared browser-extension code should be imported here without accidentally treating Safari-specific project files as part of the Firefox release boundary. New Firefox-specific long-term development should move to this directory after migration validation.
