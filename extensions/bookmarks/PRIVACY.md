# Privacy

GoreeCloud Bookmarks is a first-party Firefox extension for saving the current page to a user-controlled GoreeCloud Bookmarks deployment.

It contains no analytics, advertising, telemetry, remote executable code, or third-party tracking and does not store reusable credentials. The only application host permission is `https://bookmarks.goreecloud.com/*`.

Current-page title and URL plus user-entered collection, tags, and note text are transmitted only after the user explicitly chooses Save bookmark.
