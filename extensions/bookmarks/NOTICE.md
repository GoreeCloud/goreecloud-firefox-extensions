# Upstream Notice

The legacy GoreeCloud Bookmarks browser-extension repository was derived from the Linkwarden browser extension and remains relevant provenance for the product's browser-capture history.

The canonical Firefox implementation in this directory is being rebuilt as a GoreeCloud-controlled Firefox-specific client under the broader fork-to-native transition strategy. Where upstream Linkwarden code is copied or adapted in future work, its MIT license and attribution must be preserved with the affected source.
