# GoreeCloud Download Manager Extension 0.2.4 — Automated Test Plan

## Purpose

Move timing-sensitive Firefox scheduler verification out of repeated manual localhost interaction and into deterministic repository CI wherever the behavior can be reproduced with mocks and controlled fixtures.

## Automated gates

The 0.2.4 source candidate must pass:

- repository manifest/inventory validation;
- Python native-core, installer, recovery, cookie-permission, concurrency-server, and scheduler-contract tests;
- Node Firefox scheduler integration regression using mocked `browser.downloads` state;
- maintained JavaScript syntax checks;
- deterministic unsigned XPI packaging; and
- archive verification.

## Firefox scheduler model

The Node regression uses the production `background.js` and `scheduler_hardening.js` scripts with an in-memory mocked WebExtensions environment. It exercises:

1. queue five Firefox jobs with `maxConcurrent = 3`;
2. assert exactly three underlying Firefox downloads are created and two managed jobs remain queued;
3. pause one active job and emit Firefox's paused + `USER_CANCELED` delta;
4. assert a queued job is promoted so three managed jobs remain active;
5. resume the paused job while all three slots are occupied;
6. assert the existing Firefox job remains managed as queued and the underlying browser download is still paused;
7. emit another paused + `USER_CANCELED` delta and assert it cannot rewrite the managed queue state;
8. complete one active job;
9. assert the freed slot resumes the oldest queued existing Firefox download ID rather than creating a replacement download; and
10. assert the scheduler still has three active jobs and emits one completion notification for the completed job.

## Runtime boundary

This automated plan does not claim to reproduce Mozilla's entire browser runtime. Real Firefox/Flatpak/native-portal evidence already collected remains valid for the tested 0.2.3 baseline. Later user/device interaction should be reserved for gates that cannot be reproduced through available connected tools, especially Mozilla-signed persistent installation and full-browser restart/native-host acceptance.
