# Security Policy

GoreeCloud Webspaces is currently in active development and has no Stable release.

Please do not publish sensitive vulnerability details in a public issue before coordinated handling is available.

## Security boundaries

Webspaces relies on Firefox contextual identities for supported browser-state separation. It does not claim process isolation, a malware sandbox, VPN/IP isolation, anonymity, or complete tracking prevention.

No secrets, credentials, authentication cookies, recovery codes, or production administrative endpoints belong in this repository.
