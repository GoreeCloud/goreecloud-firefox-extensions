# GoreeCloud Advanced Tab Manager — Features

## Implemented in source candidate 0.1.0

- Manifest V3 Firefox identity and canonical component directory.
- Non-persistent ES-module background event page.
- Cold-start-safe reconstruction from live Firefox windows, tabs, and native groups.
- Firefox session-backed logical tab IDs for extension-owned tab identity.
- Live listeners for tab, window, and native-group changes.
- Sidebar showing windows, native groups, titles, URLs, pinned/audio/muted/discarded state, search, activation, close, and safe manual discard.
- Toolbar popup showing open-tab/group counts and exact duplicate counts, plus sidebar launch and status refresh.
- No host permissions, no content scripts, and private browsing explicitly disallowed by the manifest.
- Component validation, unit tests, and deterministic repository packaging integration.

## Planned / not yet implemented

Trees, Tab Sets, stashing, snoozing, rules, normalized duplicate cleanup, automatic discard policy, session snapshots, import/export, command palette, full manager/settings UI, Webspaces integration, optional hidden-tab Focus Mode, signing, runtime acceptance, and Stable qualification remain future work.
