Current boundary

This 0.1.8 manager foundation is intentionally diagnostic and read-only. It does not add import/export, session snapshots, bulk organization, destructive settings, remote management, or new Firefox permissions.

Firefox remains authoritative for live tabs, windows, and native groups. The manager displays counts and store revisions; it does not expose saved URLs, tab titles, rule contents, or browsing history.

Development source only. Representative Firefox runtime/accessibility acceptance, signing, production release, and Stable qualification remain separate gates.
