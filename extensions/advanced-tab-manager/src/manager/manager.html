What this Manager does

Session snapshot capture is bounded to restorable non-private URLs and uses additive restore into new windows. Existing live windows are not replaced or closed.

Release lifecycle, signing, and platform acceptance are intentionally not embedded as mutable truth in this runtime surface.

Local-first Firefox tab organization. Release and signing provenance are maintained in canonical GoreeCloud release records.
