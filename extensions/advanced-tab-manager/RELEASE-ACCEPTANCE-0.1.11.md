# GoreeCloud Advanced Tab Manager — Release Acceptance 0.1.11

## Status

**Version:** 0.1.11  
**Lifecycle:** Stable  
**Accepted Stable version:** 0.1.11  
**Functional delta from accepted 0.1.10 slice:** No feature expansion

0.1.11 is the release-preparation successor to 0.1.10. It preserves the accepted functional slice while correcting packaged lifecycle wording and adding explicit Stable qualification gates.

## Runtime delta

The packaged runtime delta is deliberately narrow:

- manifest version advances from 0.1.10 to 0.1.11;
- popup version text becomes lifecycle-neutral;
- Manager current-boundary/footer text becomes lifecycle-neutral and delegates release/signing truth to canonical release records;
- popup gains an explicit Forced Colors border fallback.

Permissions, add-on ID, storage schemas, browser authority, rule semantics, recovery semantics, import/export semantics, and feature behavior are otherwise unchanged.
