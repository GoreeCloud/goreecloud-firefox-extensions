# GoreeCloud Firefox Extensions Branding

Branding authority: `GoreeCloud/goreecloud-branding-assets`.

Extension icons, logos, badges, store artwork, promotional graphics, and shared GoreeCloud identity assets must be created and approved in the unified branding repository before being synchronized into this collection. Existing local artwork is a consumer derivative only and must not become an independent branding authority.

Branding does not establish extension functionality, privacy/security behavior, or release claims.
